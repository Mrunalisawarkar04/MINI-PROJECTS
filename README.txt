RideShare demo bundle
=====================

This bundle contains a polished browser prototype and a C implementation plan.

FRONTEND DEMO
1. Keep index.html in its folder.
2. Open index.html in Chrome/Edge.
3. An internet connection is needed to load Leaflet and OpenStreetMap tiles.
4. Use Request ride, Add driver, click ride rows, and Complete selected to demonstrate the UI.
5. The browser prototype uses JavaScript for the demonstration interactions. It is a visual mock/prototype and is NOT yet connected to the C program.

IMPORTANT FOR THE COLLEGE SUBMISSION
The required Graph, Queue, Hashing and Dijkstra implementation must run in C. The supplied index.html demonstrates the desired frontend experience; it does not replace the C implementation. To make the UI call C, the next step is to run a C HTTP backend and connect the buttons to its API. Do not claim that the browser demo itself is entirely C.

MAP
The map is a sample Nagpur-area illustrative map with demo nodes A-E and sample road weights. It is not live GPS or real driver tracking.
